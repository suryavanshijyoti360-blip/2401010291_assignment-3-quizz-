## Advanced Quiz Application

This project is a lightweight and responsive web-based quiz application built using HTML5, CSS3, and vanilla JavaScript. The application features a dynamic interface that allows users to select between different question categories, such as General Knowledge and Technology, ensuring a varied user experience. Each question is governed by a ten-second countdown timer, which automatically transitions to the next question upon expiration to maintain a fast-paced environment. The application also integrates audio feedback, playing distinct sounds for correct and incorrect answers to enhance interactivity.

The codebase is designed with simplicity and modularity in mind, utilizing a centralized data object to manage question sets and answer keys. The styling employs a modern dark-themed aesthetic with CSS Flexbox for centering and responsive design elements. Key functionalities include real-time score tracking, dynamic DOM manipulation for loading questions without page refreshes, and a restart capability. This project serves as an effective example of handling state, intervals, and event listeners in a front-end environment without the need for external frameworks or libraries.
